# AWS S3 File Upload Using Python

## Project Overview
A simple Python automation project that uploads a local file to an Amazon S3 bucket using the Boto3 library.

## Technologies Used
- Python
- AWS S3
- Boto3

## Features
- Upload a file to Amazon S3
- Automate file uploads using Python
- Handle common upload errors

## Prerequisites
- Python 3 installed
- AWS account and S3 bucket
- AWS credentials configured with S3 upload permissions

## Installation

Install the required library:

```bash
pip install -r requirements.txt
```

## How to Run
1. Configure your AWS credentials.
2. Replace `your-bucket-name` in `upload.py` with your bucket name.
3. Create a `sample.txt` file in the project folder.
4. Run the following command:

```bash
python upload.py
```

## Expected Output

```text
File uploaded successfully!
```
